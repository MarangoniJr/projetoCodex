Acesso do proprietário

Colunas e comandos disponíveis

expenses: id, date, type, category, amount, from, to, km, carExtra, notes, receiptName, createdAt, receipt_key e payload.

reports: reportMonth, consultant, route, company, kmRate e payload.

clients: name. projects: client, name. Use Editar para corrigir o nome também nos lançamentos vinculados, ou Excluir para remover um cadastro sem vínculos.

Para habilitar as ações, selecione name em clients e client, name em projects, sem renomear essas colunas. Exemplo: SELECT * FROM projects WHERE client = 'Nome do cliente';

Use SELECT, colunas ou *, AS, WHERE com AND, comparações (=, !=, >, <, >=, <=, LIKE), ORDER BY de uma coluna e LIMIT de 1 a 200. Textos ficam entre aspas simples. Também é aceito json_extract(payload, '$.campo').

O asterisco mostra os campos principais já separados do JSON. Inclua id ao consultar despesas para habilitar a edição. Consultas com JOIN, subconsultas, agregações e comandos de alteração não são aceitas nesta tela; para alterar valores, use Editar.

Valores de carro próprio são calculados com km × taxa do relatório + carExtra. amount é o valor de uma despesa realizada.
